# NetworkSettings

The `NetworkSettings` Template is a state wrapper around two `TextSetting` components.
It provides a Context and Provider for interacting with the component and building the 4c-api connection around.
It also provides some `ConfirmationModal` prompts for the delete action, to prevent accidental deleting of these settings.

It must be included with the provider exported from its directory in order to function.
Please see `./story/networkSettings.story.provider.js` for an example of a fully functional provider.

## Usage

Import

```javascript
import { NetworkSettings } from "../../UI/Templates"
import { Provider } from "../../UI/Templates/NetworkSettings"
```

Implement as follows

```javascript
const Settings = () => (
  <NetworkSettingsProvider>
    <Wrapper>
      <NetworkSettings />
    </Wrapper>
  </NetworkSettingsProvider>
)
```
