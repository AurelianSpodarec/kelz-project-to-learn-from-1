# Deal Code Creation

The Create Deal Code template implements a `formik` form around several fields. When the submit button is clicked, it runs the passed `onSubmit` button with the body passed as an argument. These can then be used within a `usePost` hook as desired.

An array of `providers` must also be passed to populate the `provider` Select with data.

## Usage

Import

```javascript
import { DealCodeCreate } from "../UI/Templates"
```

Implement as follows

```javascript
<DealCodeCreate
  providers={providers}
  onSubmit={body => create({ body })}
  isLoading={providersLoading || createLoading}
  onCancel={() => setOpen(true)}
/>
```
