# Lead Creation

The Create Lead template implements a `formik` form around several fields. When the submit button is clicked, it runs the passed `onSubmit` button with the body passed as an argument. These can then be used within a `usePost` hook as desired.

## Usage

Import

```javascript
import { LeadCreate } from "../src/UI/Templates"
```

Implement as follows

```javascript
<LeadCreate onSubmit={body => create({ body })} />
```
