# Lead Import

The `LeadImport` template implements a `formik` form around a `Modal` dialog, allowing users to submit files full of leads to the backend for import into the 4CNG platform.

## Usage

Import

```javascript
import { LeadImport } from "../../UI/Templates"
```

Implement as follows

```javascript
<LeadImport
  isOpen={importOpen}
  setIsOpen={val => dispatch({ type: "UPDATE_VALUE", key: "importOpen", value: val })}
  clearImport={() => dispatch({ type: "CLEAR_IMPORT_MODAL" })}
  onSubmit={body => {
    const file = get(body, "file[0]", null)
    const data = new FormData()
    data.append("file", file, file.name)

    importLead({ body: data })
  }}
  isLoading={importLoading}
  errors={importErrors}
/>
```
