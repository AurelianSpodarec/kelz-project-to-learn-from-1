# API Status

This provides a top-down view for the current API status of all providers and their Quote APIs on the platform. At a glance, it shows which APIs are currently returning responses. It also shows how long the response took to return, as well as any error messages that return from the request.

## Usage

Implementing this component requires two parts working in concert:

1. `ApiStatusAdmin`
2. `ApiStatusProvider`

`ApiStatusAdmin` contains the `Table` component for displaying the data.

`ApiStatusProvider` contains the state of the component and the API requests made to populate the table.

No panel is required for implementing this Admin component.

Implement as follows:

```javascript
<ApiStatusProvider>
  <Container>
    <ApiStatusAdmin />
  </Container>
</ApiStatusProvider>
```
