# `SubmitModal`

Much like the value triggered `Modal` described in `JourneyForm` story, the page's object can contain an array of modals that trigger in certain circumstances defined within these modal objects.

Each modal object must have four keys:

1. `fieldKey`
2. `fieldValueTrigger`
3. `title`
4. `content`

The `fieldKey` key matches a field name as defined in the `formik`. If the field's `value` matches the `fieldValueTrigger`, a modal is thrown with a title of `title` and content of `content` when the Save and Continue `Button` is clicked.

If more than one modal is eligible for display in the `SubmitModal`, then both will be present inside it. The modal will have no title, and instead the modal `content`s will be separated by `<h3>` tags.
