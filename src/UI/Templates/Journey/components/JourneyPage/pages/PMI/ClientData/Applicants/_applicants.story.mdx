# Journey Applicants

This implements the Template and Page for the Journey Applicants functionality in the PMI Sales Journey. Because this is defined within the Journey Template and requires a Story implementation, there are two directories to manage state and story - one for each case that handles a different usage.

### `story` directory

This contains a sample ApplicantsProvider, containing all of the data and information required for implementing the component within Storybook. It is only used inside this `_journey.applicants.story.mdx` file and within the `journey.applicants.test.js` file.

### `context` directory

This contains the state and queries for Applicants, and is what is used inside the actual sales journey.

The `story` provider wraps the component in the .mdx file, and the `context` provider wraps the component within `applicants.js`.
