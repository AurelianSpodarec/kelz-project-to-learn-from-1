# `JourneyForm`

The `JourneyForm` component takes an array of `sections` and renders the fields within using the `renderSectionComponent` helper function defined in `UI/Helpers/journey`.

Each field also handles value triggered `Modal` behaviours if such behaviours are attached to the field being rendered. These are handled by the `fieldValueTrigger`, `title`, and `content` keys in the field's object.
