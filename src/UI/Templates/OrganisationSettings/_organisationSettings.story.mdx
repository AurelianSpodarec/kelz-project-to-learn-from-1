# OrganisationSettings

The `OrganisationSettings` Template exposes a `Tabs` organism composed of a `Tab` for Sales, Journey and Quick Quote Settings.
It provides a Context and Provider for interacting with the component and building the 4c-api connection around.

It must be included with the provider exported from its directory in order to function.
Please see `./story/organisationSettings.story.provider.js` for an example of a fully functional provider.

## Usage

Import

```javascript
import { OrganisationSettings } from "../../UI/Templates"
```

Implement as follows

```javascript
const Settings = () => (
  <OrganisationSettingsProvider>
    <OrganisationSettings />
  </OrganisationSettingsProvider>
)
```
