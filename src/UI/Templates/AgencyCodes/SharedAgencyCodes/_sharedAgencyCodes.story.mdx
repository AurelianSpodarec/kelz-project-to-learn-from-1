## SharedAgencyCodes

The `SharedAgencyCodes` component displays the information from the `/self-service/:slug` query for use by the user. The user can edit their details and settings using this view. It is accessible by clicking your username and email address in the top-right corner of the screen.

The `self-service/:slug` query itself is actually based in the `Page` component, which wraps the React Router `Switch` and exposes this information on the `PageContext`. This is so that the `UserInformation` subcomponent in the `Header` can access the same details as the `MyAccount` component without refetching the same query on every page load.

The `selfServiceUpdate` function - also exposed on `PageContext` - is used to update the `/self-service/:slug` data without refetching the query whenever the user runs the `PATCH` request on that endpoint successfully. This will instantly update the user's name and email address in the `UserInfo` subcomponent as well, as they are both based on the same data source.

```javascript

```
