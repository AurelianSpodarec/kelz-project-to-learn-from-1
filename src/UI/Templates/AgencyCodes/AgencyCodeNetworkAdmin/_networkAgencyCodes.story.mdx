# Network AgencyCode Administration

The `AgencyCodeNetworkAdmin` component allows you to view agency codes and commision rates on the platform. It is designed to be used in multiple different contexts, as the platform requires different views for agency codes in different states, and these require their own pages.

## Usage

Implementing this component is more complicated than usual because there are three components that must be defined and implemented separately in order for it to work. This is because different contexts for `AgencyCodeNetworkAdmin` have different visual design guidelines that must be worked around. Developers therefore need more control over how these components are implemented.

There are three main parts to this component:

1. `AgencyCodeNetworkAdmin`
2. `NetworkAgencyCodesPanel`
3. `AgencyCodesProvider`

`AgencyCodeNetworkAdmin` contains the `Table` component for displaying the index agency codes data as well as several tools for sorting and refining the Index agency codes query.

`NetworkAgencyCodesPanel` is a `FlyOutPanel` component that contains the View agency code and Edit agency code functionality. Because `FlyOutPanel` is an absolutely positioned element, it must be defined at the root of the page being designed. It is for this reason that a React context is desirable for managing the state of this component.

`AgencyCodesProvider` is the Context Provider. It controls the state of the `AgencyCodeNetworkAdmin` component and the `NetworkAgencyCodesPanel` component. It must be defined outside of the component in order to allow developers to control how the queries and mutations are performed inside the multiple pages that the `AgencyCodeNetworkAdmin` component is defined within. Different implementations of `AgencyCodeNetworkAdmin` will have slightly different needs, and using a context to control the state will allow for that.

Although the particular state management technique within the context is left open, it makes sense to use a `useReducer` hook for state management of page actions.

An example of a functional `AgencyCodesProvider` instance can be found inside `./story/networkAgencyCodes.story.provider.js`. Refer to this when considering the bare minimum of fields required to make this component functional.

Implement as follows:

```javascript
<>
  <Container>
    <AgencyCodeNetworkAdmin {...props} />
  </Container>
  <NetworkAgencyCodesPanel {...props} />
</>
```
