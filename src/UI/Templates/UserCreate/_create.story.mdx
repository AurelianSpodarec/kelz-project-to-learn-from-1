# User Creation

The Create User template implements a `formik` form around several fields. When the submit button is clicked, it runs the passed `onSubmit` button with the body passed as an argument. These can then be used within a `usePost` hook as desired.

## Usage

Import

```javascript
import { UserCreate } from "../src/UI/Templates"
```

Implement as follows

```javascript
<UserCreate onSubmit={body => create({ body })} />
```
