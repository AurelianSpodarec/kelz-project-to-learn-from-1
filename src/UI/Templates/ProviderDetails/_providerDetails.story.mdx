# ProviderDetails

The `ProviderDetails` component allows users to view details about the selected insurance provider. This same component can also be used to edit those details.

## Usage

This component must be paired with the included Provider and Context in order to function. Relevant queries should be passed to the `ProviderDetails` component through the use of this context provider.

Example:

```javascript
<ProviderDetailsProvider
  value={{
    data,
    isEdit,
    setEdit,
    onEditDetailsSubmit: body => editDetails(body)
  }}
>
  <ProviderDetails />
</ProviderDetailsProvider>
```
