# NetworkOrganisations

The `NetworkOrganisations` component allows the logged-in user to view a network's organisations. They can view in-depth information about the member organisation, view that organisation's quotes and policies, or remove them from the network.

## Usage

There are three main parts to this component:

1. `NetworkOrganisations`
2. `NetworkOrganisationsPanel`
3. `NetworkOrganisationsProvider`

`NetworkOrganisations` contains the `Table` component for displaying the index network organisations data as well as several tools for sorting and refining the Index Organisations query.

`NetworkOrganisationsPanel` is a `FlyOutPanel` component that contains the View Organisation data, `Button`s to redirect to the quotes or policies view, and a `Button` to initiate the remove organisation action.

`NetworkOrganisationsProvider` is the Context Provider. It controls the state of the `NetworkOrganisations` component and the `NetworkOrganisationsPanel` component.

An example of a functional `NetworkOrganisationsPanel` instance can be found inside `./story/networkOrganisations.story.provider.js`. Refer to this when considering the bare minimum of fields required to make this component functional.

Implement as follows:

```javascript
<NetworkOrganisationsProvider>
  <Container>
    <NetworkOrganisations {...props} />
  </Container>
  <NetworkOrganisationsPanel />
</NetworkOrganisationsProvider>
```
