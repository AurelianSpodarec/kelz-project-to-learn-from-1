# OrganisationDetails

The `OrganisationDetails` component allows users to view details about the selected IFA. This same component can also be used to edit those details.

## Usage

This component must be paired with the included Provider and Context in order to function. Relevant queries should be passed to the `OrganisationDetails` component through the use of this context provider.

Example:

```javascript
<OrganisationDetailsProvider
  value={{
    data,
    isEdit,
    setEdit,
    onEditDetailsSubmit: body => editDetails(body)
  }}
>
  <OrganisationDetails />
</OrganisationDetailsProvider>
```
