# Deal Codes Administration

The `DealCodeAdmin` component allows the logged-in user to view deal codes, edit them, delete them, or add new deal codes to the platform.

### Usage

Implementing this component requires three components working in concert:

1. `DealCodeAdmin`
2. `DealCodesPanel`
3. `DealCodesProvider`

`DealCodeAdmin` contains the `Table` component for displaying the index deal codes data as well as several tools for sorting and refining the Index Deal Codes query.

`DealCodesPanel` is a `FlyOutPanel` component that contains the View Deal Code and Edit Deal Code functionality.

`DealCodesProvider` is the Context Provider. It controls the state of the `DealCodeAdmin` and `DealCodesPanel` components.

An example of a functional `DealCodesProvider` instance can be found inside `./story/deals.story.provider.js`.

Implement as follows:

```javascript
<DealCodesProvider>
  <Container>
    <DealCodeAdmin />
  </Container>
  <DealCodesPanel />
</DealCodesProvider>
```
