# OrganisationOnboarding

The `OrganisationOnboarding` Template exposes `Typography` elements, Activation and
Approval status `IconWithText`s, a collection of `Checkboxe`s and a `ConfirmationModal` driven by data from `OrganisationOnboardingContext`.

It must be included with the provider exported from its directory in order to function.
Please see `./story/organisationOnboarding.story.provider.js` for an example of a fully functional provider.

## Usage

Import

```javascript
import { OrganisationOnboarding } from "../../UI/Templates"
```

Implement as follows

```javascript
const Settings = () => (
  <OrganisationOnboardingProvider>
    <OrganisationOnboarding />
  </OrganisationOnboardingProvider>
)
```
