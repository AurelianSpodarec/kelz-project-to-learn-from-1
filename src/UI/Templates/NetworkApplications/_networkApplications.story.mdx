# NetworkApplications

The `NetworkApplications` component allows the logged-in user to view, sort, filter, accept, and reject applications to join the network.

## Usage

Implementing this component requires two components that must be defined and implemented separately.

1. `NetworkApplications`
2. `NetworkApplicationsProvider`

`NetworkApplications` contains the `Table` component for displaying and interacting with the index network applications data.

`NetworkApplicationsProvider` is the Context Provider. It controls the state of the `NetworkApplications` component.

An example of a functional `NetworkApplicationsProvider` instance can be found inside `./story/networkApplications.story.provider.js`.

Implement as follows:

```javascript
<>
  <Container>
    <NetworkApplications {...props} />
  </Container>
</>
```
