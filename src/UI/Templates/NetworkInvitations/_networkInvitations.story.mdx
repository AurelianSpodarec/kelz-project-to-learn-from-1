# Network Invitations

The `NetworkInvitations` component is designed to allow network administrators and system administrators to view, remove, or create invitations to join a network.

## Usage

There are two main parts to this component:

1. `NetworkInvitations`
2. `NetworkInvitationsProvider`

`NetworkInvitations` contains the `Table` component for displaying the index invitations data as well as tools for sorting and filtering the invitations.

It also contains tools for adding new invitations and cancelling existing invitations.

`NetworkInvitationsProvider` is the Context Provider. It controls the state of the `NetworkInvitations` component.

An example of a functional `NetworkInvitationsProvider` component instance can be found inside `./story/networkInvitations.story.provider.js`.

Implement as follows:

```javascript
<NetworkInvitationsProvider>
  <Container>
    <NetworkInvitations {...props} />
  </Container>
</NetworkInvitationsProvider>
```
