# Networks Administration

The `NetworkAdmin` component allows the logged-in user to view networks, edit them, delete them, or add new networks to the platform.

## Usage

Implementing this component requires three components that must be defined and implemented seperately in order for it to work.

1. `NetworkAdmin`
2. `NetworksPanel`
3. `NetworksProvider`

`NetworkAdmin` contains the `Table` component for displaying the index networks data as well as several tools for sorting and refining the Index Networks query.

`NetworksPanel` is a `FlyOutPanel` component that contains the View Network and Delete Network functionality.

`NetworksProvider` is the Context Provider. It controls the state of the `NetworkAdmin` and `NetworksPanel` components.

Although the particular state management technique within the context is left open, it makes sense to use a `useReducer` hook for state management of page actions.

An example of a functional `NetworksProvider` instance can be found inside `./story/networks.story.provider.js`.

Implement as follows:

```javascript
<>
  <Container>
    <NetworkAdmin {...props} />
  </Container>
  <NetworksPanel {...props} />
</>
```
