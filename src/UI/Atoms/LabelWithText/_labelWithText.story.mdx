# LabelWithText

`LabelWithText` is a simple presentational component that displays a label positioned above a text element.

By default, this text element is indented.

## Usage

This component can display text by using a `content` prop or by wrapping children within the `LabelWithText` tag.

Import

```javascript
import { LabelWithText } from "../../UI/Atoms"
```

Usage

```javascript
<LabelWithText label="Label" content="Use the content prop for standard styles" />
```

```javascript
<LabelWithText label="Label" margin="0 0 2rem">
  <p style={{ margin: "0" }}>
    This can also be used with children, however, it is desirable to use the margin prop on the
    LabelWithText component instead of the margin on the wrapped text.
  </p>
</LabelWithText>
```
