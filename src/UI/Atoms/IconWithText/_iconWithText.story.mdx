# IconWithText

`IconWithText` is a simple presentational component that puts an icon alongside a text element.

## Usage

This component can display text by using a `content` prop or by wrapping Text children in the element.

Import

```javascript
import { IconWithText } from "../../UI/Atoms"
```

Usage

```javascript
<IconWithText icon="check" content="Use the content prop for standard styles" />
```

```javascript
<IconWithText icon="checklist" margin="0 0 2rem">
  <p style={{ margin: "0" }}>
    This can also be used with children, however, it is desirable to use the margin prop on the
    IconWithText component instead of the margin on the wrapped text.
  </p>
</IconWithText>
```
