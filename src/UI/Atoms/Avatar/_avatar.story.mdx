# Avatar

The `Avatar` is a simple atom component creating initials from `firstName` and `lastName` of user

## Usage

Import

```javascript
import { Avatar } from "../src/UI/Atoms"
```

Implement as follows

```javascript
<Avatar first={test} last={test} />
```
