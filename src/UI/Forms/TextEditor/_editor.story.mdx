# TextEditor

The `TextEditor` component is an implementation of the [CK Editor Rich Text Editor for React](https://ckeditor.com/docs/ckeditor5/latest/builds/guides/integration/frameworks/react.html), wrapped in a very simple styled component.

It is intended to be used where the user is expected to supply valid HTML for storage as a string on the backend.

Only simple controls have been exposed on the toolbar - basic typography markup and lists. This can be addressed later as required, however, this component is meant to be used to supply simple text-based HTML only.

## Usage

Import

```javascript
import { TextEditor } from "../../UI/Forms"
```

Implement as follows

```javascript
<TextEditor name="story" formik={formik} />
```
