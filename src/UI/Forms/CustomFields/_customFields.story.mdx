# CustomFields

The `CustomFields` component is designed to allow a form to handle adding multiple phone numbers or email addresses to be attached at form submission.

## Usage

Import

```javascript
import { CustomFields } from "../../UI/Organisms"
```

Implement as follows

```javascript
<CustomFields name="custom_fields" formik={formik} label="Custom fields" />
```

`CustomFields` can **only** be used in conjunction with a `formik` instance. An initial value of `{type: "", value: "", description: ""}` should be passed in the form

Example formik definition:

```javascript
const validationSchema = object({
  custom_fields: array(
    object({
      type: string().label("Custom field type").required("MISSING_REQUIRED_FIELD"),
      value: string()
        .when("type", {
          is: "email",
          then: string().email("INVALID_EMAIL")
        })
        .when("type", {
          is: "phone",
          then: string()
            .test("Phone invalid", "INVALID_PHONE", val => {
              if (!val) return false
              return isValidPhoneNumber(val, "GB")
            })
            .required("MISSING_REQUIRED_FIELD")
        })
        .required("MISSING_REQUIRED_FIELD"),
      description: string().optional()
    })
  )
})
const formik = useFormik({
  initialValues: {
    custom_fields: []
  },
  validationSchema
})
```
