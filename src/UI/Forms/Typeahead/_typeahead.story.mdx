# Typeahead

The Typeahead is designed to be implemented alongside a `useGet` query. It has an `onDebouncedChange` prop, a function which fires 500ms after the user stops typing. This can be used to update a variable outside of the `Typeahead` component, which runs a query and updates the list of suggestions. If suggestions are present, they will be displayed in the dropdown below the `Input` component.

## Story

export const Template = args => {
  const validationSchema = yup.object({
    story: yup.string().required()
  })
  const formik = useFormik({
    initialValues: {
      story: ""
    },
    validationSchema,
    onSubmit: body => console.log(body)
  })
  return (
    <div style={{ width: "50rem" }}>
      <Typeahead {...args} name="story" formik={formik} />
      <button type="submit" onClick={formik.handleSubmit}>
        Submit
      </button>
    </div>
  )
}
