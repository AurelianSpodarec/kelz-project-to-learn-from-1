# FileList

The `FileList` component provides standard dressing for a list of files. It is meant to be used in conjunction with the `FileSelect` in 4c-elements, in particular with regard to implementing Logo Upload and parts of the client journey.

## Usage

This component only requires a single prop - `files`. This can either be an `array` or a `FileList` object.

If a `FileList` is passed, the component will convert it to an array before use. This is necessary because `FileList` cannot make use of native array methods.

Import

```javascript
import { FileList } from "../../UI/Molecules"
```

Usage

```javascript
<FileList files={files} />
```
