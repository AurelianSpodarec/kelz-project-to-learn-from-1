## Notes

The `Notes` component is will create a user messages context along with timestamp and username.

## Usage

Import

```javascript
import { Notes } from "./src/UI/Molecules"
```

Implement as follows

```javascript
<Notes />
```

### Data Structure

In order to render a note properly, it must be have the following keys:

| Key        | Description                                                                     |
| ---------- | ------------------------------------------------------------------------------- |
| id         | String. The unique identifier for this note.                                    |
| note       | String. The content of the note.                                                |
| user       | Object. The user who created the note. Must have first_name and last_name keys. |
| created_at | String. A timestamp to mark when the note was created.                          |
