# Page

The `Page` component wraps around the router in `App.js`. It provides the `Header`, `Footer`, and `Navigation` components around the `Content` window. The `FlyOutPanel` controls are located in this component and exposed to all subordinate components using a Provider.

The `/self-service/{user}` GET query is run from this component and exposed via provider, too, because its data is exposed to the `Header` and used within `MyAccount`. This is done to prevent visual bugs caused by a mismatch between the user information in the `AuthProvider` and `Header`/`MyAccount.`

By exposing it on the Provider here, we can make use of it within `MyAccount` and the `Header` at the same time without unnecessary refetching.

The `PageContext` can be used to access these variables. This should be imported from the `/UI/Organisms` root when it needs to be used.

When used as part of various components, the stories containing or being decorated with `Page` **must** have `layout: "fullscreen"` in the `parameters={{}}` prop.

## Usage

It should not be necessary to import and use the `Page` component within the application, but it is still sometimes necessary to import the `Page` for use in unit tests.

```javascript
import { Page, PageContext } from "../../UI/Organisms"
```

Use the context as follows:

```javascript
const { setPanelStatus, panelStatusControls } = React.useContext(PageContext)
```

Inside `test.js` files, use the Page as follows:

```javascript
const { getByTestId } = renderWithTheme(
  <Page>
    <TestComponent />
  </Page>
)
```

## Subcomponents

### Header

The `Header` has branding information. Clicking the 4C Logo will return the user to the dashboard page ("/").

It also displays information about the logged-in user on the right-hand side, and clicking it brings the user to the `My Account` page.

### Footer

The `Footer` component displays copyright information and the current version of the platform.

### Navigation

The navigation menu accepts a `dashboard` array and builds styled `Link` components to populate the Navigation menu based on that array.
